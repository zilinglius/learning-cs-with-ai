# 计算机专业基础课 AI 使用手册（Learning CS with AI）

**从“复制粘贴”到“人机共驾”，别让 AI 替你长肌肉。**

这是一份面向低年级计算机专业本科生（大一、大二）的纯粹学习方法论指南，聚焦 **Linux 环境**下的四门核心基础课：**程序设计（C/C++）**、**数据结构**、**计算机系统基础（CSAPP）**与**离散数学**。

> 👉 **直接阅读完整手册：[guideline.md](./guideline.md)**

## 为什么要写这份指南？

在 AI 生成代码和推导几乎零成本的今天，低年级同学最容易掉进**“流利度错觉”**——看着 AI 写出的工整代码或“显然可得”的证明，以为自己已经学会，结果一进考场、一遇复杂段错误、一到高年级系统课就束手无策。

这本手册不反对使用 AI，也不做空洞说教，而是用一套可落地的工程工作流，帮你划清**“哪些无效摩擦应该交给 AI 提效，哪些有益摩擦必须死守在自己大脑里”**，把 AI 从“写作业的枪手”改造成你的专属学习工具。

## 手册核心内容

| 模块 | 核心内容 |

| **序章：晚上八点，余票变成了 42 亿张** | 用一场真实线上故障，一比一映射 C/C++、数据结构、CSAPP、离散数学四门课的底层价值 |

| 所处阶段 | 建议先读章节 | 优先启用模板 |
| :--- | :--- | :--- |
